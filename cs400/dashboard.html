Accepted folder layouts

Class folders
dataset.zip
  class_a/image1.png
  class_a/image2.png
  class_b/image1.jpg
  ...

At least 10 distinct images per class. We save an approximately 70% / 15% / 15% train / validation / test split, stratified by class.

Your own splits
dataset.zip
  train/class_a/...
  validation/class_a/...
  test/class_a/...
  ...all classes in each split

Use this format for subject- or source-based splits. Exact images crossing splits or labels are rejected.

Use ordinary single-label classification images. Automatic splitting cannot detect related subjects or near-duplicates. Custom corruption robustness needs a separate domain benchmark; this workflow reports clean test accuracy after search.

Search settings

MOTPE jointly searches ResNet depth/width, SGD or AdamW, learning rate, weight decay, dropout and augmentation. Multi-fidelity promotion is enabled.

Optional customization

Start first runs a three-epoch largest-model calibration. Search begins only if the estimated startup plus one cohort fits your budget. Calibration and final clean-test evaluation are additional to the active search allocation. A short demonstration checks operation; it is not a quality benchmark.

Keep the laptop plugged in and the server terminal open. Closing this browser does not stop the worker. Use Pause, wait for confirmation, then shut down.
